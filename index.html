Atajo para Envío rápido
En la app Atajos crea uno llamado Gracias Lote:
1. Obtener archivo GraciasATi.mp4 (carpeta Shortcuts de iCloud), sin selector.
2. Dividir texto: Entrada del atajo, separador personalizado @@@.
3. Repetir con cada elemento del texto dividido:
  · Dividir texto: Elemento de repetición, separador |||
  · Obtener elemento: Primero → variable Numero
  · Obtener elemento: Último → variable Mensaje
  · Enviar mensaje: Archivo a Numero
  · Enviar mensaje: Mensaje a Numero
  · Esperar 3 segundos
